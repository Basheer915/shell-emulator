# Эмулятор UNIX-подобной командной оболочки

Графический эмулятор командной оболочки, разработанный на языке Java
в рамках учебного задания.

## Описание

Проект представляет собой графическое приложение, имитирующее работу
UNIX-подобной командной оболочки.

Пользователь вводит команды в поле ввода, после чего программа
разбирает команду, определяет соответствующий обработчик и выводит
результат выполнения.

## Используемые технологии

- Java 21
- Gradle
- Swing
- JUnit 6

## Текущая функциональность

На этапе 1 реализованы:

- графический интерфейс приложения;
- заголовок окна с именем пользователя и именем компьютера;
- поле для ввода команд;
- разбор команды на имя и аргументы;
- диспетчеризация команд;
- заглушка команды `ls`;
- заглушка команды `cd`;
- команда `exit`;
- обработка неизвестных команд;
- обработка неправильного количества аргументов.

## Поддерживаемые команды

### `ls`

Заглушка команды `ls`, которая выводит переданные аргументы.

Примеры:

```text
ls
ls file.txt
ls file1.txt file2.txt
